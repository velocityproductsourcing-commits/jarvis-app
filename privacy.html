Jarvis privacy policy

Last updated: October 11, 2026

Jarvis is a personal assistant app used only by its owner, Pete Kleinwaks. It is not offered to anyone else.

What Jarvis accesses

  • Google Calendar: reads the owner's events and adds events the owner asks for.
  • Google Drive: reads files in one folder the owner set up for Jarvis, and creates its own files in that folder.

How the data is used

Only to answer the owner's own questions and carry out the owner's own requests. The data stays on the owner's own computer and Google account.

Sharing

No data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
